The tool is now called skqe, part of Skyrim Query Engine. The old name was spf.

## Changed

- **New names:** spf.exe is now skqe.exe, and the zip is skqe-<version>.zip.
- **Databases:** the tables spf_meta and spf_modules are now skqe_meta and skqe_modules, so rebuild any existing database with skqe build-db before using skqe db add on it, and update queries that use the old table names.

## Upgrading

Delete spf.exe and its patterns.json from the old folder, then unzip this one. Scripts that call spf need to call skqe.
