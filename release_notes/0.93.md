Adds pipe-separated output and xEdit's field names, and fixes accented text that came out as replacement characters.

## New

- **skqe export --psv:** the same as --csv, separated by | instead of commas. It suits long text such as book pages, and imports into Excel with the | delimiter and UTF-8 chosen.
- **skqe fields --names:** adds xEdit's name for each field, such as CNAM - Description, when the catalog has one.

## Fixed

- **Accented text:** text stored as Windows-1252 lost its accented letters, curly quotes and dashes to replacement characters. It now reads correctly. Text in another code page, such as a Russian mod's, shows the wrong letters but is no longer lost.

## Upgrading

Databases you've already built keep the old text until you rebuild them with skqe build-db.
