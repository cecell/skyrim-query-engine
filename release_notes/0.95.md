A corrected and larger pattern catalogue, lookup tables with names for coded values, more asset facts, and one self-contained skqe.exe with its own icon.

## New

- **Catalogue: 2,010 patterns** (was 1,893). 179 patterns corrected (signed and unsigned values, floats, 4-character codes, named members, older form versions, script data) and 117 field signatures that the Creation Kit can write but the Bethesda plugins don't use, such as destruction stages on more record types.
- **Lookup tables in build-db** (schema 9): condition functions, value lists, flag lists, data types and display rules as ut_ tables, and the columns that use a value or flag list are linked to it.
- **skqe export --labels:** shows the name next to each coded value and flag.
- **build-assets:** geometry and skin-partition strips for meshes, lip files, more Havok facts and every name a Havok file carries (beth-asset-metadata 0.4.0).
- **One file:** patterns.json, ut_reference.sql and search_filters.txt are built into skqe.exe, so the exe runs on its own. skqe --version says which copy of each it uses.
- **An icon** for skqe.exe.

## Fixed

- skqe help no longer mentions a conflict command that skqe doesn't have.

## Upgrading

Unzip over the old folder, then delete patterns.json and search_filters.txt from it: a copy next to skqe.exe is used instead of the built-in one, so an old patterns.json would hide the new catalogue. To keep your own search rules, use %LOCALAPPDATA%\skqe\search_filters.txt.
