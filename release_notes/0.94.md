Adds file search across Data, BSA contents and mod staging folders, and finds where Vortex or Mod Organizer 2 keeps your mods.

## New

- **skqe search:** finds files by name, including files packed in BSAs. Plain text, wildcards or --regex, and folder names can be part of the search. Data only by default.
- **skqe search --all:** adds the staging folder. Each path is listed once, and a file hardlinked between Data and a mod counts as one copy.
- **skqe search --winner:** the one copy of each path the game uses: the loose file, else the last-loaded archive.
- **Search filters:** each file type is looked for only in its usual folders, which makes searches for one type faster. The rules are in search_filters.txt and can be edited. --anywhere and --bsa-only ignore them.
- **skqe staging:** finds the mods folder for Vortex or Mod Organizer 2. --set-data and --set-staging save your own folders instead.
- **skqe build-assets --staging auto:** uses the same detection.

## Upgrading

Unzip over the old folder, keeping search_filters.txt with skqe.exe. To change the filter rules, copy that file to %LOCALAPPDATA%\skqe\search_filters.txt and edit the copy.
