First release: read any field of any Skyrim SE plugin as JSON or CSV, from one command-line tool.

## New

- **spf info:** a plugin's header, masters and record counts by type.
- **spf fields:** every field a record type has in a plugin, so you know what to ask for.
- **spf export:** the fields you choose of the forms you choose. FormIDs come out as Owner.esm:XXXXXX, and localized text as text, from loose strings files or BSAs.
- **spf export --load-order:** every copy of a form across a load order with the winner marked, and optionally only the fields that differ.
- **spf diff:** what differs between copies of a plugin with the same name, such as two versions of a mod.
- **spf build-db:** a whole load order as one SQLite database, with winners and FormID references.
- **spf build-assets:** every asset file in Data, BSAs and mod staging folders as one SQLite database.

## Known limits

- Skyrim SE plugins only.
- Corrections from a decompilation of the Creation Kit are still being applied to the field catalog, so some fields called unknown or unused have a known meaning, and a few layouts are incomplete.
- `spf export --conflicts` compares values as they read; it isn't xEdit's conflict status.
- This tool only reads. It never changes a plugin.
