Ask a database in plain English with skqe dbq; flag and value lists get names you can guess; diff --raw shows the bytes that differ.

## New

- **skqe dbq:** ask a build-db or build-assets database a question in plain English, such as `skqe dbq "which meshes use femalehead.dds"`, `"spells with the flag fire and forget"` or `"iron swords"`. It finds the names in the question (files, plugins, FormIDs, editor IDs, display names), picks the matching question and runs that question's tested SQL, read-only; it never writes SQL of its own. Each answer starts with how it read the question. It has an interactive console with follow-ups, paging, `/sql`, `/csv` and `/json`; `--json` / `--csv` for scripts; `--list` for every question it knows. The questions cover every column and details pane of the WHAM shell extension and what the other skqe commands return. You can teach it your own words. Every question is saved locally in `%LOCALAPPDATA%\skqe\dbq\history.jsonl`; nothing leaves your PC.
- **skqe db use:** remember the database(s) dbq asks, once.
- **diff --raw:** besides the decoded fields, every subrecord whose bytes differ between copies, as hex per copy, plus the record header's flags and form version when they differ, and the same for the TES4 header (`header_raw`). Forms whose bytes differ while their decoded fields don't are listed too and counted in `summary.forms_with_only_byte_differences`.
- **skqe_version table:** in plugin and asset databases: who built it and when, who last added to it, and the layout (DDL) and fill (DML) versions.
- **st_record_types view:** every record type in a plugin database.

## Changed

- **NPC_ keeps its fourth character:** tables and names made from NPC_ are now `npc_` and `npc__snam` (was `npc`, `npc_snam`), like every other four-character signature.
- **Flag and value list names:** the ut_ lists are named after the record type and field they belong to: `{rt}_{fs}` for flags (no `_flags` suffix), `{rt}_{fs}_{field}` for value lists, `{rt}_head` for a record's header flags and `any__head` for the flags every record has. A list used by several record types is now one list per use.

## Upgrading

The plugin database schema is now 11 and the asset database schema 5: rebuild databases with build-db / build-assets. `db add` refuses an older database until it is rebuilt. Queries that name `npc` tables or the old `..._flags` list names need the new names.
