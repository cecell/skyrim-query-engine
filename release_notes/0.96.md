build-db now gives each plugin's header form version a column of its own: tes4.form_version.

## New

- **tes4.form_version:** the form version from each plugin's TES4 record header (44 = saved by an SE tool, 43 = LE, older numbers from older Creation Kit builds), as a plain number in the last column of tes4. Nothing else in tes4 or tes4_data moved.

## Upgrading

The database schema is now 10: rebuild databases with build-db to get the new column. `db add` refuses a schema 9 database until it is rebuilt.
